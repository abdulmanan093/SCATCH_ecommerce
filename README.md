# Scatch - Modern E-Commerce Platform

Scatch is a **full-featured eCommerce web application** built using the **MERN stack**. It provides users with a seamless shopping experience while offering store owners an efficient management system.

## Features

### 🛍️ User Experience
- User-friendly interface with **responsive design**
- Secure **user authentication & authorization**
- **Cart & Checkout** functionality with real-time updates

### 🛒 Product Management
- Dynamic **product catalog** with detailed product pages
- **Search & filter** functionality for easy product discovery
- Add to cart, remove, and update cart items

### 🎯 Admin Dashboard
- Manage **products, orders, and users** efficiently
- **Order tracking** and status management
- Role-based **access control** for security

### 🔗 Tech Stack
- **Frontend:** React.js, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Authentication:** Firebase/Auth or JWT
- **Deployment:** Vercel

## 🚀 Getting Started

### Installation
```bash
# Clone the repository
git clone https://github.com/abdulmanan093/SCATCH_ecommerce.git

# Navigate to project folder
cd scatch-ecommerce

# Install dependencies for frontend and backend
yarn install  # or npm install
```

### Running the Application
```bash
# Start the backend server
cd backend
yarn start  # or npm start

# Start the frontend
cd frontend
yarn start  # or npm start
```
